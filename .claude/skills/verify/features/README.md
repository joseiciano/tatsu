# Feature map

Each file describes one user-facing feature: how a user reaches it, how to
drive it with the `verify` harness, and what end state proves it works.

## Features

- [Workflow run](workflow-run.md): Run workflow here… launch sheet, step strip, Needs you and step tabs on a worktree.
- [Workflows section](workflows-section.md): full-screen Workflows section (sidebar button, hotkey, palette) with the Runs tab: Needs you, Active and Recent run cards.
